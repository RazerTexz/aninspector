## Building
### Windows
```cmd
.\gradlew assembleDebug & rem Output: app/build/outputs/apk/debug/app-debug.apk
```

### Linux / macOS
```bash
./gradlew assembleDebug # Output: app/build/outputs/apk/debug/app-debug.apk
```
